Inspección y reconstrucción de archivos

Mira dentro antes de guardar.

Gatekeeper inspecciona los archivos que recibe tu aplicación, elimina contenido activo y entrega una copia reconstruida si supera los controles.

Ver la integración ↗ Ver qué hay en el archivo ↓

Gatekeeper comprueba que el archivo sea un PDF y busca contenido activo. En este ejemplo encuentra JavaScript que podría ejecutarse al abrirlo.

La reconstrucción elimina el JavaScript, las acciones automáticas y los adjuntos. Si la copia supera los controles, tu aplicación puede descargarla.

Cómo funciona

Del archivo original a una copia lista para usar.

Quien sube un archivo controla su extensión y el encabezado Content-Type. Gatekeeper comprueba el contenido antes de permitir una descarga.

  1. 01

    Firma real

    Lee los primeros bytes y decide el tipo. Solo pasan JPEG, PNG y PDF.

    python-magic
  2. 02

    Reconstrucción

    Recodifica las imágenes desde los píxeles y quita EXIF. Limpia el PDF de JavaScript, acciones automáticas y archivos embebidos.

    Pillow · pikepdf
  3. 03

    ClamAV

    Escanea con firmas que se actualizan solas, dentro de un worker sin acceso a internet.

    firmas locales
  4. 04

    VirusTotal

    Consulta la reputación del hash SHA-256. El archivo nunca se sube.

    API v3

Integración

Sube, consulta y descarga.

Envía un archivo con tu API key, consulta el estado del análisis y descarga la copia cuando esté lista.

  1. POST /v1/files

    Envía el archivo

    La API responde al instante con un ID. El análisis corre en segundo plano.

    ›_ Bash
    $ 
    curl -i -X POST https://35-168-228-65.sslip.io/v1/files \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" \
  -F "file=@foto.jpg"

    Respuesta de ejemplo

    HTTP/1.1 202 Accepted
content-type: application/json

{"id":"3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47","estado":"pendiente"}
    ›_ PowerShell
    PS> 
    Invoke-RestMethod -Method Post -Uri https://35-168-228-65.sslip.io/v1/files `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" } `
  -Form @{ file = Get-Item .\foto.jpg }

    Respuesta de ejemplo

    id                                   estado
--                                   ------
3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 pendiente

  2. GET /v1/files/{id}

    Consulta el resultado

    El estado pasa de pendiente a limpio, en cuarentena o rechazado.

    ›_ Bash
    $ 
    curl -s https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" | jq

    Respuesta de ejemplo

    {
  "id": "3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47",
  "estado": "limpio",
  "tipo_detectado": "image/jpeg"
}
    ›_ PowerShell
    PS> 
    Invoke-RestMethod -Uri https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" }

    Respuesta de ejemplo

    id                                   estado tipo_detectado
--                                   ------ --------------
3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 limpio image/jpeg

  3. GET /v1/files/{id}/content

    Descarga la copia reconstruida

    Solo existe cuando el estado es limpio. El original nunca se entrega.

    ›_ Bash
    $ 
    curl -s https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47/content \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" \
  -o foto-limpia.jpg -w "%{http_code}\n"

    Respuesta de ejemplo

    200
    ›_ PowerShell
    PS> 
    Invoke-WebRequest -Uri https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47/content `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" } `
  -OutFile foto-limpia.jpg

Garantías

Cómo se aíslan los archivos.

Ningún original llega a tu app
Solo se puede descargar la versión reconstruida, y solo cuando el análisis terminó en limpio.
El worker no tiene internet
El único componente que abre archivos vive aislado, sin usuario root y con límites de CPU y memoria. Un archivo que explotara una librería no podría comunicarse hacia afuera.
Solo el hash sale a VirusTotal
La consulta de reputación envía el SHA-256. El contenido del archivo nunca deja tu infraestructura.
Sin metadatos ocultos
La reconstrucción elimina EXIF, incluida la ubicación GPS que suelen llevar las fotos.
Cada liberación deja rastro
Sacar un archivo de cuarentena es una decisión de administrador, con motivo obligatorio, usuario y fecha en la bitácora.

Límites

Límites de la inspección.

Qué cubre Gatekeeper y qué debes gestionar en tu aplicación.

Formatos admitidos

Solo acepta JPEG, PNG y PDF. SVG, comprimidos y documentos de Office se rechazan por diseño.

Análisis por firmas

El análisis por firmas puede pasar por alto malware nuevo. La reconstrucción ayuda a eliminar contenido activo de los formatos admitidos.

Lector de PDF

Limpiar el PDF elimina sus elementos activos, pero no protege contra fallas del lector de PDF de quien lo abre.

Pasa el cursor o pulsa una card para detenerla y leerla.

También ten en cuenta

  • No analiza el significado del contenido: un PDF de phishing con texto engañoso puede quedar como limpio.
  • Los originales en cuarentena se eliminan a los 30 días.
