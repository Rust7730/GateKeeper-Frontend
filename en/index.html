File inspection and reconstruction

Look inside before you store.

Gatekeeper inspects files sent to your application, removes active content and delivers a reconstructed copy once it passes the checks.

See the integration ↗ See what’s inside ↓

How it works

From the original file to a copy you can use.

The uploader controls the file extension and the Content-Type header. Gatekeeper checks the contents before allowing a download.

  1. 01

    File signature

    Reads the first bytes to identify the type. Only JPEG, PNG and PDF are accepted.

    python-magic
  2. 02

    Reconstruction

    Re-encodes images from their pixels and strips EXIF. Removes JavaScript, automatic actions and embedded files from PDFs.

    Pillow · pikepdf
  3. 03

    ClamAV

    Scans with automatically updated signatures inside a worker with no internet access.

    Local signatures
  4. 04

    VirusTotal

    Checks the reputation of the SHA-256 hash. The file is never uploaded.

    API v3

Integration

Upload, check and download.

Send a file with your API key, check the scan status and download the copy when it is ready.

  1. POST /v1/files

    Send the file

    The API returns an ID immediately and scans the file in the background.

    ›_ Bash
    $ 
    curl -i -X POST https://35-168-228-65.sslip.io/v1/files \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" \
  -F "file=@foto.jpg"

    Example response

    HTTP/1.1 202 Accepted
content-type: application/json

{"id":"3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47","estado":"pendiente"}
    ›_ PowerShell
    PS> 
    Invoke-RestMethod -Method Post -Uri https://35-168-228-65.sslip.io/v1/files `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" } `
  -Form @{ file = Get-Item .\foto.jpg }

    Example response

    id                                   estado
--                                   ------
3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 pendiente

  2. GET /v1/files/{id}

    Check the result

    The status changes from pending to clean, quarantined or rejected.

    ›_ Bash
    $ 
    curl -s https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" | jq

    Example response

    {
  "id": "3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47",
  "estado": "limpio",
  "tipo_detectado": "image/jpeg"
}
    ›_ PowerShell
    PS> 
    Invoke-RestMethod -Uri https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" }

    Example response

    id                                   estado tipo_detectado
--                                   ------ --------------
3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47 limpio image/jpeg

  3. GET /v1/files/{id}/content

    Download the reconstructed copy

    The copy is available when the status is clean. Gatekeeper never delivers the original.

    ›_ Bash
    $ 
    curl -s https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47/content \
  -H "Authorization: Bearer $GATEKEEPER_API_KEY" \
  -o foto-limpia.jpg -w "%{http_code}\n"

    Example response

    200
    ›_ PowerShell
    PS> 
    Invoke-WebRequest -Uri https://35-168-228-65.sslip.io/v1/files/3f2b9c1e-7a41-4c0e-9d2b-5e8f1a6c0d47/content `
  -Headers @{ "Authorization" = "Bearer $env:GATEKEEPER_API_KEY" } `
  -OutFile foto-limpia.jpg

Guarantees

How files are isolated.

Your app never receives the original
Only the reconstructed copy can be downloaded, and only when the scan finishes with a clean result.
The worker has no internet access
The only component that opens files runs in isolation, without root privileges and with CPU and memory limits. A file exploiting a library would have no network access.
Only the hash goes to VirusTotal
The reputation lookup sends the SHA-256 hash. File contents never leave your infrastructure.
Hidden metadata is removed
Reconstruction strips EXIF metadata, including GPS coordinates often embedded in photos.
Every release is logged
An administrator must give a reason to release a quarantined file. The reason, user and date are logged.

Limits

Inspection limits.

What Gatekeeper covers and what your application needs to handle.

Supported formats

Only JPEG, PNG and PDF are accepted. SVGs, archives and Office documents are rejected by design.

Signature scanning

Signature scans may miss new malware. Reconstruction helps remove active content from supported formats.

PDF reader

PDF sanitization removes active elements. Vulnerabilities in the PDF reader remain a separate risk.

Hover or press a card to pause and read it.

Also keep in mind

  • Gatekeeper does not interpret the meaning of file contents. A phishing PDF with misleading text may be marked clean.
  • Quarantined originals are deleted after 30 days.
