# `tools/claude-commands`

Fuente versionada de los comandos de Claude Code del proyecto. Se instalan en `.claude/commands/` con `npm run setup:claude` (ver E-003).

| Archivo              | Comando                     |
| -------------------- | --------------------------- |
| `modulo-inicio.md`   | `/modulo-inicio mNN nombre` |
| `modulo-cierre.md`   | `/modulo-cierre mNN`        |
| `registrar-error.md` | `/registrar-error "título"` |
